# 高通机型刷机后卡在 QDL/9008 或反复重启的恢复

## 症状

两种典型表现：

其一，刷机工具显示完成，但设备始终黑屏，插上电脑后一直停留在下载模式：

```text
端口 (COM 和 LPT)
  Qualcomm HS-USB QDLoader 9008 (COM5)
```

设备不会自己退出 9008，也没有开机电流变化。

其二，设备能亮屏但进不去系统：

```text
开机出现品牌 logo → 黑屏 → 自动重启 → 循环
```

有时伴随「能进 recovery 但进不了系统」「解锁提示 unlocked 后卡住」「设置里基带版本为空、无信号」等。

## 原因

- 刷入的固件不完整或与机型不匹配，尤其是引导链相关分区缺失/错误时，设备在早期引导阶段就失败并回落为 EDL/QDL 模式。
- 分区表或分区内容与设备实际布局不一致，或只补刷了部分镜像，导致引导校验不通过。
- 刷写中途断电、掉线，造成部分分区只写了一半（日志里往往能看到写失败，见 [[qualcomm-emmc-ufs-flash-write-failure]]）。
- persist、modemst/fsg 等校准分区被覆盖或擦除：轻则指纹/传感器失效、基带异常，重则影响开机流程的完整性。

## 步骤

1. **先让设备稳定停在 9008**，不要反复拔插和乱按组合键。进入方法与端口确认见 [[qualcomm-edl-9008-enter]]。
2. **做一次完整全量刷写**：使用与机型严格对应的官方线刷包，不要只补刷单个分区。刷写全程保证供电与线材稳定，中途不要拔线、不要切 USB 口。
3. **检查引导链是否漏刷**：不同平台的分区名不同（以 ROM 内 `rawprogram*.xml` / `patch*.xml` 实际列出的分区为准），确认该包要求的全部引导类分区都已写入，且 `patch` XML 中的分区与设备 GPT 对应。
4. **仍然回落 9008 时考虑重新分区**：分区表损坏或与 ROM 不匹配时，需要走重新分区/全盘刷写流程，方法与风险见 [[qualcomm-emmc-ufs-flash-write-failure]]。
5. **刷完不要急着反复重启**：首次开机可能较慢，给它足够时间。若确实反复重启，重新进 fastboot/EDL 完整刷一次，并抓取完整日志，确认没有隐藏的写失败或超时。
6. **persist 分区的正确做法**：只恢复**本机自己**的 persist 备份。没有备份时，绝对不要用其他机器的 persist 镜像覆盖，否则指纹/传感器校准数据永久丢失，刷机无法恢复。官方全刷包里是否包含可用的 persist 镜像视具体 ROM 而定，不确定时不要刷该分区。
7. **modem / 基带问题**：若刷完能进系统但无信号、设置里基带版本为空，用本机对应 ROM 里的 modem 类镜像重新刷入（不同平台文件名不同，如 `modem` 分区镜像、`NON-HLOS.bin` 一类）。若 modemst/fsg 校准分区已丢失或被写坏，普通刷机无法重新生成，需要专业工具或官方售后处理。
8. **锁与权限问题**：fastboot 被锁或无法解锁会导致刷写被拒，参见 [[fastboot-unlock-failed]]；安全启动机型在 EDL 下被认证拦截时参见 [[qualcomm-secure-boot-nop-sig-tag]]。

## 验证

- 设备不再被枚举为 9008，设备管理器里出现正常的 Android / MTP 设备；
- 屏幕能点亮并进入系统，首次开机时间明显长于平时属正常；
- 连续重启两次以上不再进入循环，也不会再回落 9008；
- 设置中能看到非空的基带版本，插卡后能识别信号；指纹、传感器等功能正常；
- `adb devices` 能列出设备并正常授权。

## 待确认

- 不同平台（是否有独立 xbl/abl 等分区、是否 A/B 分区）对应的最小可启动分区清单；
- 官方全刷包中 persist 镜像到底是有效校准数据还是空占位，随机型和 ROM 而异；
- modemst/fsg 校准数据在何种条件下可由官方工具重新生成。
